# ARISE — Hunter System

A Solo Leveling-inspired productivity dashboard where everyday goals become quests. Complete quests, earn XP, level up, and build a daily streak.

## Features

- Create quests with a title, category, and difficulty
- Earn XP for completing quests:
  - Easy: 10 XP
  - Medium: 25 XP
  - Hard: 50 XP
- Level up for every 100 XP, with extra XP carried over
- Progress through ranks as you level up
- Track completed quests, today’s completions, and your daily streak
- Save progress in your browser with `localStorage`
- Responsive dark blue-purple System-inspired interface

## Run locally

No frameworks, packages, or build step required.

1. Download or clone this repository.
2. Open `index.html` in your browser.
3. Create your first quest and start earning XP.

## Project files

- `index.html` — Dashboard structure and quest form
- `style.css` — Responsive layout and visual styling
- `script.js` — Quest actions, XP, leveling, streaks, and saved progress

## About saved progress

ARISE stores progress in the browser that you use to open the app. It isn’t synced between browsers or devices. Clearing that browser’s site data will remove the saved progress.
